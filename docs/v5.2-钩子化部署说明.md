# 钩子化：让门禁从「自觉遵守」变成「结构强制」

## 为什么必须做

你的 enforce.py 目前只在 AI **主动调用**时生效。绕过测试：

```
$ echo "SECRET_KEY=leaked" > .env     # 不调 enforce.py，直接写
退出码=0  文件已落盘
```

外部实验数据：文本规则 135/135 全被跳过；挂到闸门后 0/135 违规。
**你的脚本已经是对的，只差把它挂到工具层。**

## 安装（按宿主选一个）

### Claude Code
```bash
mkdir -p .claude/hooks
cp hooks/*.sh .claude/hooks/
cp settings-claude-code.json .claude/settings.local.json
```

### CodeBuddy
```bash
mkdir -p .codebuddy/hooks
cp hooks/*.sh .codebuddy/hooks/
cp settings-codebuddy.json .codebuddy/settings.json
```

### Trae
```bash
mkdir -p .trae/hooks
cp hooks/*.sh .trae/hooks/
cp settings-trae.json .trae/settings.json
```

### Cursor
`.cursor/rules/` 不支持 PreToolUse 钩子 → **改用 git pre-commit 兜底**（见下）

### 通用兜底（推荐所有宿主都装）
```bash
cp pre-commit .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
```
这条连 AI 在终端里直接 `git commit` 都拦得住。

## 挂上之后的效果

| 场景 | 挂钩前 | 挂钩后 |
|---|---|---|
| AI 用 Write 工具写 .env | 不调就放行 | **自动拦截** |
| AI 用 `echo > file` 绕过 | 放行 | **Bash 钩子拦截** |
| AI 偷偷 import 未声明模块 | 依赖自觉 | **pre-commit 拦截** |
| AI 改 WORKFLOW.md 铁律 | 依赖自觉 | **check-write 核心区拦截** |

## Fail-Close 原则

钩子脚本自己崩了 → **默认拒绝**，不是放行。
（否则防火墙失效时反而全开，比没有更危险）

## 验证安装

```bash
# 应被拦截
python3 scripts/enforce.py check-write .env && echo "✗ 未生效" || echo "✓ 生效"
```
