> 反向工程自 ncwu（华北水利水电大学）多轮实战，覆盖 2026-10-01 全部讨论。

## 阶段 0 · 天花板预判与资产分级（开工前强制）

### 0.1 先判断能打到哪，别打到一半才发现

| 约束 | 直接排除的方向 |
|---|---|
| 无凭证 | 越权、水平/垂直权限、需登录的业务逻辑 |
| 不可写 | 注入验证、上传验证、所有"做了不该能做的"型漏洞 |
| 只读 GET | 绝大多数中高危 |

**结论要写在报告开头**：本目标在无凭证条件下，可预期的只有**信息泄露 + 未授权访问 + 组件版本**三类。

### 0.2 资产分级（决定请求分配，本项目最大的分配事故）

| 级别 | 数据类型 | 本项目实例 | 投入应占 |
|---|---|---|---|
| **一级** | 成绩 / 学籍 / 身份证 / 认证凭据 | jwmis 教务、my 门户、authserver | **≥50%** |
| **二级** | 校内敏感、教工信息、邮件 | mail / webmail / vpn / 各院系子站 | 30% |
| **三级** | 公开统计量、新闻、点击数 | www / news / www2 门户 | ≤20% |

**本项目实际：三级资产耗了十几轮，一级资产零投入。这是分配事故，不是技术问题。**

### 0.3 资产归属判定（避免提交被驳回）

| 类型 | 处置 | 本项目实例 |
|---|---|---|
| 本校自持 | 深挖 | www / news / www2 / jwmis / authserver |
| 厂商托管（本校域） | 可报，注明厂商 | jwmis（青果）、www（博达） |
| **第三方 SaaS** | **仅记录，不提交** | jyxx（bysjy 就业平台） |

### 0.4 零探测资产清单必须建表

本项目遗漏（截至最后一轮仍未探测）：
```
my.ncwu.edu.cn      统一身份认证平台门户   ← 一级，数据价值最高，从未打开
mail / webmail      邮件系统               ← 二级
vpn.ncwu.edu.cn     VPN                    ← 二级
www5 / wza / xlcs / stxyhtdsj              ← 二级/三级
```
**规范要求：阶段 0 结束时，所有已发现子域必须进表并标注探测状态。**

## 阶段 1 · 响应基线（新增，最关键）

### 1.1 先建立该目标的"响应字典"，再谈探测

用随机路径对每个面取基线，**每个面独立建，不跨面套用**：

| 面 | 基线 | 含义 |
|---|---|---|
| 主站网关 | 1693B | 网关未放行 |
| 主站应用 | 2455B | 穿透网关，文件不存在 |
| 主站鉴权 | 912B | 博达登录前置 |
| jwmis filter | 577B | 青果保护页 |
| jwmis 原生 | 649B | Tomcat 裸奔（**页脚会打印版本**） |
| jwmis 不存在 | 1266B | 路径不存在 |
| authserver | 1982B/1986B | 金智独立链（**有 Envoy**） |

### 1.2 分层原则（本项目最核心的认知）

> **网关层和应用层是两个世界。**
> - 网关：粗粒度按前缀拦，狠但零信息
> - 应用层：按需鉴权，有遗漏，**响应有差异 = 能对话**

**前 215 个请求全废，是因为一直在敲城墙，没进城。**

### 1.3 0B 单独处置（硬性）

**0B ≠ 无逻辑。** 它只能证明"没输出"，不能证明"没处理"。

```
clicktimes.jsp 缺参 → 0B，带参 → 1135
```
同一端点、同一 0B，可能是"查无"，也可能是"写入成功"。
**0B 必须标记为「受理但无回执」，可能是被掩盖的已发生写入。**

### 1.4 缓存识别

`Cache-Control: max-age=600` 存在时，**md5 一致只能证明"同一缓存周期内一致"**，不能证明同源。

## 阶段 2 · 目标自述路径（新增，发请求之前强制）

### 2.1 先把页面读完，再发包

**字典命中率 ≈ 0；目标自述路径命中率高一个数量级。**

本项目：十几轮后在登录页 grep 出 10 条真实功能路径（含"查看成绩"），**历史零探测**。

### 2.2 提取方法

```
grep -o 'href="[^"]*"'    page.html
grep -o 'onclick="[^"]*"' page.html
grep -o 'location.href[^;]*'
grep -o "_webRootPath[^;]*"     ← 拼接路径变量
```

### 2.3 编码坑

青果系为 **GBK**，直接 grep 中文关键词返回 0 —— **先 `iconv -f GBK -t UTF-8` 再提取**。
本项目首轮四关键词零命中，误判成"路径不存在"，实为编码问题。

### 2.4 自述路径优先级（按数据敏感度）

| 梯队 | 特征 | 实例 |
|---|---|---|
| 一 | 成绩/准考证/个人信息 | `zgks.xwkszkz.html?flag=1` |
| 二 | 课表/班级/教师 | `dykb.*.html` |
| 三 | 本来就公开 | 校历 / 作息 / 通知 |
| 四 | 运维信息 | `frame/version.html` |

## 阶段 3 · 形态探测（新增核心）

### 3.1 同一路径必须测四种形态

```
目录    /examples/
文件    /examples/index.jsp
后缀    /examples/servlets/servlet/HelloWorldExample
编码    /%2e%2e%2f  ·  /%252f
```

**判据**：主站 `/examples/` = 1693B（拦），`/examples/index.jsp` = 2455B（穿）。
**网关按形态分流，不是按前缀封闭。**

### 3.2 一句话原则

> **"这个路径不存在"和"我用错了形态"是两回事，后者在本项目连犯两次。**

### 3.3 上下文覆盖

jwmis：青果 filter 只保护 `/hsjw/`，**根路径是裸 Tomcat**（`/docs/` 返回 649B 原生而非 577B）。
**别把"我测的那个上下文锁着"当成"整个系统锁着"。**

## 阶段 4 · 鉴权测绘

### 4.1 措辞红线

| ✅ 写 | ❌ 不写 |
|---|---|
| 未观察到鉴权拦截 | 已确认无鉴权 |
| 篡改公开统计数据 | 可写入任意数据 / 可执行代码 |
| 依据前端源码推断，未实际触发 | 已验证存在 |

**0B 不等于无鉴权的证明。**

### 4.2 写端点定性法（不触发写入）

```
缺参请求 → 观察返回
  非 912B（在鉴权名单外）→ 值得往下走
  912B（被拦）          → 放弃
```
**绝不带完整参数打写端点。** 本项目 `datainput.jsp` 曾误发全参，大概率已落库一条。

### 4.3 危害边界必须写清

参数全为数字型（脏数据回退 -1）→ **天花板是数据完整性，不是代码执行**。
写超了，审核一追问就穿帮。

## 阶段 5 · 联网 CVE 校核（强制，禁凭模型）

### 5.1 四个必查维度

| 维度 | 本项目教训 |
|---|---|
| **最新年份** | 执行报告停在 2025 库，漏掉 2026 一大批（68763 / 59083 / 79677 / 65182 / 68525） |
| **边界值** | 9.0.108 正好是 CVE-2025-55752 影响范围的最后一个版本 |
| **有无补丁** | Tomcat 7 = **No fix**（永久）；9.0.108 = 升 9.0.122 可修（临时）—— **处置完全不同** |
| **真实危害** | CVE-2025-55754 标题像 RCE，实为 ANSI 控制台操纵，官方列 Low |

### 5.2 版本证据强度分档

| 来源 | 强度 |
|---|---|
| 目标自身错误页打印（`Apache Tomcat/9.0.108`） | **实锤** |
| 栈类名 + 厂商公告（博达 9.x → Tomcat 7） | 强（双重印证） |
| 纯推断 | 不可作证据提交 |

### 5.3 "运行未修复组件"是独立可提交项

判据三条全中即可交，不依赖单条 CVE 可利用：
1. 版本精确可证
2. 命中公开 CVE 且未修复
3. 资产重要性

> **"我没能利用" ≠ "没有漏洞"。** 本报告曾把前者写成结案理由。

## 阶段 6 · 根因聚类与横向移动

### 6.1 低危不是终点，是根因指针

| 根因 | 正确动作 |
|---|---|
| 接口未鉴权 | 找同根因下**更高价值**的实例 |
| 错误未脱敏 | 合并同类，抽技术栈 |
| 默认资源未清理 | 枚举同批实例 |
| 第三方配置 | **孤立，不合并** |

### 6.2 纵向 vs 横向

> ❌ 在低价值端点上反复深挖（本项目在点击计数上耗十几轮）
> ✅ 抽根因后横向移动到高价值实例

点击计数端点的参数语义挖到底了（三级状态、四参数、转义机制），**再挖一万次也还是点击计数**。
根因是"无鉴权"，但无鉴权的更高价值实例**在教务系统，不在 news/click 目录里**。

## 阶段 7 · 定级与措辞

| 发现 | 级别 | 说明 |
|---|---|---|
| 文件存在性可区分（六态 oracle） | **低危** | CWE-548 定 low；它是钥匙不是漏洞 |
| 错误响应泄露版本栈 | 低危 | 可合并多条 |
| 未授权访问公开数据 | 中危 | 可能被判不敏感而降级 |
| 未授权访问**教务数据** | 高危 | 成绩/学籍 |
| 运行无补丁的 EOL 组件 | 中危~高危 | 独立可提交项 |

**跨实例证据要写进报告**：「跨 www/news/www2 三实例普遍存在」比单点强一档。

## 五项制度

### 制度一 · 请求预算
每轮**明确给 N 个请求**，每个附判据表。
> 本项目给 3 个请求，执行方多次以"请求少"给出模糊答案。

### 制度二 · 授权口径一次性锁定
开工前引用平台原文条款定死层级，中途不允许自行收紧。
> 本项目执行方中途以"未核实授权"为由，18 请求清单整轮未执行。

### 制度三 · 失败即信息
400 / 500 / 302 / RST **全部存档分析**，禁止记为失败丢弃。
> L6 那次 400（本为测试失败）成了十几轮最大突破：`VAppServer/6.0.0` + 完整栈 + Java 8。

### 制度四 · 否定结论入库
Ghostcat、CAS service 绕过、SAML XSW、忘记密码、manager、examples……
**否定结论省掉后续几十个请求，是资产不是废数据。**

### 制度五 · 证据三态标注
每个结论标 **实锤 / 推断 / 排除**，避免后期把推断当实锤提交。

## 反模式清单（出现即纠正）

| 反模式 | 正确做法 |
|---|---|
| 拿字典扫路径 | 先读页面取自述路径 |
| 只看状态码 | 记录 Content-Type + Length + md5 |
| 一次只测一种形态 | 目录 / 文件 / 后缀 / 编码四种 |
| 0B = 无逻辑 | 0B = 受理无回执，可能是写入 |
| 凭模型答 CVE | 必须联网，查最新年份 |
| 跨面套用基线 | 每面独立建 |
| 在低价值端点纵向深挖 | 抽根因横向移动 |
| 把推断写成实锤 | 三态标注 |
| 排除项不留证据 | 否定结论入库 |
| 中途改授权口径 | 开工前锁定 |

## 纪律（硬性）

- **可写端点清单单独维护并全程封存**（本项目 9 项），任何轮次不得触碰
- 间隔 ≥7s，分时段跑（本项目观察到约 3 个请求即可能触发限流）
- 零登录、零表单、零爆破、零注入语义
- `%2e` / `%2f` 属**观察性探测**（看回显形态），不是遍历利用
