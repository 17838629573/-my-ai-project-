# 视频工作流

自然语言 → 物理驱动 → 逐帧生图 → 合成出片 的完整工作流。

## 这条管线做什么

给一句自然语言（如「雨夜鹅卵石街上，一位撑伞女子缓步走来」），
代码自动完成：

1. **题材解析**：拆出实体（人/旗/树/背景），判族（biped / cloth / vegetation / rigid / backdrop）
2. **机位求解**：由「景别 + 角度 + 共现约束」解出相机 7 自由度，而不是手填或从图反推
3. **物理计算**：步态（周期/步长/足端轨迹/摆臂）、风响应（按族查 Strouhal 表）、雨（滴谱/终速/倾角/溅射）全部由公式算出
4. **结构性提示词**：把物理点逐帧写进生图提示词（如「左足摆动·抬 0.185m」），不用「正在迈步」这类模糊词
5. **一次一物体生图**：按 sheet_plan 编排出图集（1 张图含 N 格），上一批末格作下一批身份参考，压画风漂移
6. **抠像与合成**：GrabCut（Rother-Kolmogorov-Blake 2004）+ 自动 trimap，Porter-Duff 线性光预乘合成
7. **出片**：按周期反推帧数，循环闭合可校验

## 目录

- `WORKFLOW.md` —— 主干总纲（3.3K），分册路由在文件内
- `contracts/` —— 50 份模块契约：只写依赖/被依赖 + 铁律 + 改前必读指针
- `IMPROVE_*.md` —— 26 份改进记录：业界依据、已搜证参数、踩坑复盘
- `params_ai.json` —— 代码反问 AI 后落盘的物性参数（带来源与区间）
- `gate_*.py` —— 三道门禁：模块体积 / 文档体积 / 产物体积

## 设计约定（改代码前必读）

- 原子只定义一次（`_common.py`），禁止在业务模块重写 `clamp` / `x % 360` 等
- 代码缺参数 → 抛 `AskAI` 反问，禁止心里默算、禁止静默兜底
- 数值一律由公式算出，禁硬编码坐标；相机高度由参照物反解
- 物体 vs 背景由「族 + 是否参与物理」判定，`backdrop` 不分配交点

## 不含媒体

仓库只含代码与文档（约 1.2M）。生成的图集、成片、音频不入库，
按 `.gitignore` 排除，可随时重跑生成。
