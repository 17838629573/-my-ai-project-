## 二、铁律41 的完整理由（素材张数必须代码输出）

`frames`（渲染帧数，如 136）≠ `mat_frames`（素材张数，如 16）。
AI 看到 136 会去生成 136 张图（不可能），或不知道该生成几张而随手定
（如固定 24/36），导致素材与骨架错位、±15% 钳制报错。

| 字段 | 含义 | 谁用 |
|---|---|---|
| `mat_frames` | AI 须生成的素材张数（图格数） | AI 生图 |
| `sheet.rows/cols` | 单张图集网格排布 | AI 生图 |
| `sheet_plan()` | 图集规划（几张/每张几格/每格像素/背景色） | AI 生图：铁律55-57 |
| `sheet.phase_map` | 第 i 格对应相位角（度） | AI 生图 |
| `playrate` | 一张素材停留几个渲染帧 | 代码播放 |

## 三、动力学：chain 族（受迫阻尼链）

**统一结构**：凡"部分动、部分不动"的物体都是同一结构——驱动点（动）→ 附属体（被动响应）。

```
树干→枝条   头皮→发丝   肩/腰→衣摆   幡身末端→垂带
```

`pendulum2` 是其二级特例；N 级即 `chain`。**不新建族，只推广。**

权威依据：Moore 2002（Oregon State 博士论文）实测——
> 枝条振荡频率 ≈ **整棵树的自然频率**，而非枝条自身固有频率；
> 枝条表现为**受迫阻尼谐振子**，驱动频率 = 整棵树自然频率。

### 四个公式（全部代数式，无微分方程）

```
ω_n = √(3EI / (m_eq·L³))        m_eq = 33/140·m·L   等效质量
r   = ω_drive / ω_n             频率比
M   = r²/√((1-r²)²+(2ζr)²)      放大因子（base excitation 相对位移）
φ   = atan2(2ζr, 1-r²)          相位滞后
A   = M × A_drive               实际响应振幅
```

### 接口

```python
spec = {
  "family": "chain",
  "drive": {"f_hz": 1.0, "amp_m": 0.02},
  "links": [
      {"L":0.30, "m":0.010, "EI":1.0e-4, "zeta":0.10},
      {"L":0.10, "m":0.003, "EI":2.0e-5, "zeta":0.10},
  ],
}
```

逐级递推：每级的驱动 = 上一级末端的响应。**ζ 由 AI 搜（或取宽松默认）。**

## 四、动力学：transient（瞬态衰减）

**冲击波 = 突然的大风**，物理上正确；解的形式从"稳态"换成"瞬态"。

```
A_env(t) = A_steady + (A_peak - A_steady)·exp(-ζ·ω_n·(t - t_0))
ω_d      = ω_n·√(1-ζ²)
τ        = 1/(ζ·ω_n)            时间常数
N50      = ln2/(2πζ)            衰减到 50% 所需周期数
N5       ≈ 1/(2ζ)               衰减到 5%
```

来源：NASA NTRS 脉冲响应函数 `h(t) = (1/mω_d)·e^(-ζω_n t)·sin(ω_d t)`；
包络取 `e^(-ζω_n t)`。等价于结构动力学对数衰减率 δ=2πζ。

**关键**：冲击过后回到 `A_steady`（原扰动量），不是回到 0。

## 五、briefing_text()：代码必须输出任务包（铁律33）

**AI 会忘，代码不能忘。** 每次做视频，代码必须主动输出"AI 该做的事"。

真实入口（契约=代码，逐个对应）：

```python
survey()                      -> 第①步提问：本片有哪些物体
inventory(actors)             -> 第②步：每建一个美术资源就反问动/静角色
assemble(ans)                 -> 组装：族、待搜物性、填到哪/跑什么(HOWTO)
briefing_text(b, with_examples=True) -> 可读任务包；with_examples 附硬编码示例(铁律37)
solve(spec)                   -> 物理求解；缺槽即报错(铁律31)
probe_plan(ans, probe_max=8)  -> 探针计划(铁律48)
probe_check(...)              -> 探针一致性4项(铁律47)
containment_check(...)        -> 每格容纳/留边/同尺度(铁律47)
```

`actors` 由分镜声明；未声明即报错（不静默给空包）。
