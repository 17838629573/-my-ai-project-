### Stage 3.5 按需拉取闭环（一次只处理当前这一个物体）
```
① 代码提问：本镜需要 X，物性如下（尺寸/质量/约束方式）
② AI 搜公式 → 算无量纲数 → 回给代码
③ 代码校验硬约束 → 提问"需要参考图集"
④ AI 搜多张参考 → 合成一张图集（24帧网格）
⑤ AI 搜真实尺寸 → 填 scene_spec → 代码校验 px/m 一致性
⑥ 代码校验通过 → 图生图 → 序列帧入库
```
**每次只跑一个物体。** 不为未用到的物体预计算。

## 三、资产分类铁律（见 contracts/actors.md）
```
能动 → actor（人/动物/植物/门/旗/水/火），必须可驱动
动不了 → 背景（城池/房屋/地形/远山），静态整图
```
背景图禁止烘焙可动件。驱动不了 = HALT，禁降级禁占位。

## 四、AI 填写契约（见 AI_INPUT.md）
```
AI 填：mass / kind / cd / b_vogel / surface / 真实尺寸（物性，可搜，标源）
代码算：area / force / accel / displacement / px_per_m（派生量，禁手填）
```
三档：有据（必搜+标源）｜估算（按 kind 取默认）｜N/A（不适用，非漏填）

## 十、参数声明铁律（param_decl / cloth_aero）

- **铁律99**：代码内部缺失参数时，禁止 AI 心里默算、禁止静默兜底 → 必须 `param_decl.require()` 抛 `AskAI` 反问
- **铁律100**：落盘参数必须有 `source`（文献/标准/厂商文档），无来源拒绝（防幻觉）
- **铁律101**：必须带 `range` 合理区间，越界拒绝；`value` 须在区间内

详见 `contracts/param_decl.md`（依赖/被依赖）与 `IMPROVE_param_decl.md`（业界依据+真坑+待办，改前必读）。
