# qcheck —— 无参考视频质量检测（纯数学，无模型权重）

## 为什么不用 VMAF / PSNR / VQMT
它们是**全参考**指标，需要"正确答案"视频做基准。生成视频没有参考。
VMAF 还是为**压缩失真**设计的，不是测抖动。
本工具只用**相邻帧互相比较**那一类（上一帧当参考，这个基准我们有）。

## 两层
| 层 | 测什么 | 模块 |
|---|---|---|
| 像素层 | 一致性：冻结 / 闪烁 / 光流 / 帧间SSIM | qc_freeze, qc_flicker, qc_flow, qc_ssim |
| 物理层 | 自然度：步态锁相 / 足锁 / 平衡 / 滑移 | qc_phys |

**只装像素层只能解决一半问题**：一个人同手同脚走路，光流平滑、SSIM 高、
不闪不卡，所有像素指标全绿 —— 但看着就是不自然。
自然度得靠物理判据（已建在 interaction 域）。

## 用法
```
python3 -m _tools.qcheck.qc_run <video> [--json out.json]
python3 -m _tools.qcheck.qc_run <好视频> --calib <其它视频...>   # 阈值标定
python3 -m _tools.qcheck.qc_run <video> --phys phys.json         # 接物理层
```

## 阈值必须自己标定
业界默认值是给压缩视频定的，不适用生成视频。
用 `--calib` 以自己的成片为基准跑出分布再定。

## 实测（合成样本 320x240 / 40帧 / 30fps）
| 样本 | frozen | flicker | flow_std | motion_std | min_ssim |
|---|---|---|---|---|---|
| 正常平移 | 0.00 | 0 | 0.067 | **0.008** | 0.960 |
| 冻结段 | **0.15** | 0 | 0.496 | 2.406 | 0.893 |
| 闪烁 | 0.00 | **8** | 1.423 | 0.784 | **0.357** |
| 跳变 | 0.05 | 0 | 0.210 | **1.082** | 0.953 |

关键：**跳变样本只有 motion_smoothness_std 能抓到**（0.008 → 1.082，133 倍），
SSIM 抓不到（0.953 仍很高）—— 因为 aligned SSIM 会把跳变也对齐掉。

## 已知缺陷（实测逼出来的）
1. **冻结只看 rho 会误判平滑运动**：缓慢平移 rho=0.935 > 0.85，整段误报。
   已修：叠加 FD 双阈值（真冻结 FD≈0，平滑运动 FD 非零）。
2. **Farneback 对随机噪声纹理失效**：测试素材须用结构化图案。
3. **物理层需要求解器参数**，命令行不传则跳过。
