# character_sheet 改动史

## 序列帧命名必须两位补零（实测确认）

命名约定：`character_animation_frame.png`，全小写、下划线、帧号**两位补零**。

原因（实测）：

```python
sorted(['xz_walk_2','xz_walk_10'])
# → ['xz_walk_10', 'xz_walk_2']   10 排在 2 前面！
```

不补零会在几乎所有文件浏览器与打包工具中**静默重排动画顺序**。

已加 `check_naming()`，构造违例实测能抓出"非全小写""未补零"两类。
走路 8 帧文件名同步改为 `wk_walk_01..04`。
