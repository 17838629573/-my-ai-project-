# Stage 1 接需求（叙事文本）

## 自然语言输入（业界六要素：主体+动作+运镜+环境+风格+时长）

> 秋日黄昏，唐代古城墙马道上，一位身披赭红僧袍的僧人自左向右缓步行走；
> 道旁一株老柳在四级风中摇曳、枝叶起伏；城头一面朱红幡旗迎风舒展、旗角翻卷。
> 镜头固定平视中景，暖金色侧逆光，电影写实风格，时长八秒。

| 要素 | 内容 |
|---|---|
| 主体 | 僧人 / 老柳 / 朱红幡旗 |
| 动作 | 行走（缓） / 摇曳（风驱） / 飘扬（风驱） |
| 运镜 | 固定机位，平视中景 |
| 环境 | 秋日黄昏，古城墙马道，天空暖金 |
| 风格 | 电影写实，暖金侧逆光，浅景深 |
| 时长 | 8 秒 @60fps = 480 帧 |

## 拆节拍（beat：一个 beat = 一个叙事事件）

1. 确立：秋日古城墙马道（环境基调）
2. 僧人自左向右缓步行走（主体动作）
3. 柳树在四级风中摇曳（环境响应）
4. 幡旗迎风舒展、旗角翻卷（环境响应）
