# Stage 0 定方案（搜行业标准）

## 业界流程（多来源一致）

来源：novakit.ai / domer.io / promptifyvideo.com / oakgen.ai / flux-art.net

```
文案(自然语言) → 拆节拍(beat) → 分镜表(shot list)
    → 锁连续性常量(角色块/地点/调色/镜头族/画幅帧率)
    → 关键帧(每镜一张, 第一张为风格基准, 后续以其为参考图)
    → 图生视频/首尾帧补间 → 组装 → 校验 → 交付
```

**业界明确的反向警告**：先生成片段再编故事 = "一堆漂亮但接不起来的素材"。
正确方向是 script → shot list → storyboard → generation。

## 业界自然语言六要素（视频提示词模板）

```
主体(谁/什么) + 动作(动词,幅度) + 运镜(静/推/摇/跟)
+ 环境(地点/天气/时间) + 风格(影调/镜头/画质) + 时长/节奏
```
图像提示词描述"凝固的一瞬间"；视频提示词描述"凝固的瞬间 + 接下来发生什么"。

## 关键参数（业界经验值）

| 项 | 业界值 |
|---|---|
| 单镜时长 | 动作镜头 3-4s；静态/微动 6-8s；多数 2-6s |
| 每镜候选 | 生成 3-5 个，选最优 1 + 备份 1 |
| 相邻镜 | 不得同景别同运镜（防跳切） |
| 首尾帧 | N 张关键帧 → N-1 段视频 |
| 一致性 | 参考图 > 文字描述；角色表(正面/3/4侧/侧面) |
| 画幅 | 先按交付分辨率七八成生成，确认后放大 |

## 与本项目 Stage 映射

| 业界 | 本项目 Stage |
|---|---|
| 文案→节拍→分镜表 | S1 接需求 → S2 拆模块 |
| 锁风格圣经/角色参考 | S3 备资产（连续性常量） |
| 关键帧链式参考 | S3.5 按需拉取（一次一物体） |
| 图生视频/首尾帧 | S4 装配 → S5 渲染 |
| 组装+QC | S6 校验 → S7 交付 |
