# 契约：路径—路面对齐（铁律95-98）

## 依赖 / 被依赖

- 依赖：`path.py`（样条）、`_px.py`（px_per_m 唯一口径）
- 被依赖：`build_video.py`、`shot_plan.py`
- 改前必读：`IMPROVE_path.md`

## 铁律

**铁律95｜先找可行走表面，再定义路径**
业界 NavMesh 制作流程 Step 1 即 Find walkable surfaces（按 agent
高度/宽度/坡度能力找可行走面），Step 2 简化边界，Step 3 三角化。
**禁止在没确认表面可行走的情况下声明路径控制点。**

**铁律96｜路径控制点必须在画布内**
控制点坐标须落在 `[0,W]×[0,H]`。越界即报错，禁止静默裁剪。
（旧 scene_spec 用 x=-300…1700，画布仅 540 宽 → 大半条路在画外）

**铁律97｜生图 prompt 必须描述"可见"路面几何**
须含：画面内起止坐标、路面宽度、透视方向、材质、两侧边界物。
禁止把画布外坐标直接写进 prompt（模型无法理解）。

**铁律98｜生图后必须校验路径落在可行走面上**
采样点处若非地面（局部水平性不足 / 颜色偏离声明材质），
偏差率超阈值即报错，禁止带着"人走在墙上"出片。

## 程序负责 / AI 必做

程序负责：坐标越界判定、可行走面检测、采样点偏差率计算、阈值判定。
AI 必做：声明路面材质与颜色、确认透视方向、偏差超限时重生成背景图。
