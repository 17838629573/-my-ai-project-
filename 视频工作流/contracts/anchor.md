# contract: anchor.py —— 物理点锚点层

**状态**: 黄（新模块）

## 职责
把物性 → 无量纲数 → **物理点表**，作为生图的几何锚点。
**不画质感，只算几何。** 质感交给生图模型。

## 输入（物性，AI 填 / 代码持有）
```
L, H        几何尺寸 m
sigma       面密度或体密度
B           弯曲刚度
U           风速 m/s（由 beaufort 得）
family      模型族
```

## 输出
```
dimensionless   R1(质量比) / R2(无量纲弯曲刚度) / Re
regime          straight / flapping / chaotic / deflected
points          [(s, A/A_max, phase_lag_deg), ...]  沿弧长归一
period_s        摆动周期
```

## 模型族（先定族再取参数，见铁律14）
| family | 物理模型 | 例子 |
|---|---|---|
| `cantilever` | 标准悬臂梁一阶模态 β1=1.8751 | 旗身、树枝 |
| `pendulum2` | 二级摆（顶端受迫+自身摆动） | 垂带、衣摆 |
| `hinge` | 定轴转动 | 门、窗 |
| `free_surface` | 自由液面 | 水 |

**族选错 = 参数全错。** 垂带不是悬臂梁，是二级摆。

## 无量纲数（定义必须标源，禁混用同名不同义）
```
R1 = M* = sigma/(rho_f·L)            质量比          [Connell&Yue 2007]
R2 = K_B = B/(rho_f·U²·L³)           无量纲弯曲刚度  [Connell&Yue 2007]
Re = U·L/nu                          雷诺数
St = 2A·f/U                          斯特劳哈尔数    ← A 是振幅不是长度！
```
**铁律20**：`St=f·L/U` 与 `St=2A·f/U` 是两个定义，混用会错 1.6 倍。

## regime 判据（Izawa 2024 实测区间）
```
R2 > 4.06e-3        → straight   平直绷直
1.72e-3 ~ 4.06e-3   → flapping  大幅拍打，A/L > 1.6
R2 < 1.72e-3        → deflected 只弯不拍
```

## 硬约束（生图 prompt 必须携带）
1. `s=0` 固定端：位移=0，切角=0 —— 杆全程垂直静止
2. 末端峰峰摆幅 ≥ 1.6×L（flapping 态）
3. 沿弧长行波相位滞后，非整体同相
4. 二级摆（垂带）摆幅 > 驱动点（旗身末端）摆幅
5. St≈0.2 邻域 → 非严格周期，含不规则性

## 禁
- 禁 AI 凭空描述形态（"向后飞扬"这种软词无效）
- 禁不同尺寸共用同一个 B（B 随宽度线性变化）
- 禁把锚点表当词典沉淀（跨视频会串味，见用户裁定）
