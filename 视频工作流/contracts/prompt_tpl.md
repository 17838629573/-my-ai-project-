# 提示词模板契约（按族抽象，禁按物体写死）

## 依赖 / 被依赖

```
依赖:   无（纯模板，零业务依赖，禁 import 业务模块以免成环）
被依赖: driver（briefing 输出模板指引）、build_video（生图前取提示词）
```

## 铁律

| # | 内容 |
|---|---|
| 81 | 提示词按**族**取模板，禁按具体物体写死 |
| 82 | 模板区零具体物体名；示例可硬编码但必须在 `EXAMPLES` 标记区内 |
| 83 | 姿态描述走**结构性量**（关节角/足端坐标），禁"迈步中"等模糊词 |
| 84 | 未知族**报错**，不许静默套用相近族 |
| 85 | 每族模板必含「避免项」与「验收标准」 |

## 业界依据

- **awesome-gpt-image-2**：类别不只是标签，每个 category 对应一个 `tpl-{name}`
  结构化约束块，系统用它**编译**提示词。分类即模板，不是分类即名字。
- **Orias AI taxonomy**：提示词应**以资产角色开头**，不是以视觉风格开头；
  固定顺序 = 资产类型 → 用途 → 观众时刻 → 创意方向 → 构图 → 格式 → 避免 → 验收。
- **verified-skill imagegen**：分类后 slug 必须跨提示词保持一致；
  编辑类须显式列出 invariants（"只改 X，Y 不变"）。
- **UE5 PCG 教训**：LLM 会幻觉出不存在的资产名，PCG 图必须有**资产白名单**防御层，
  静默丢弃未登记项 —— 对应铁律84。

## 接口

```python
build(family, params) -> {"提示词", "验收", "未填", "族"}
structural_pose(family, solved) -> 结构性姿态文本   # 铁律83
families() -> 已登记族列表
```

`params` 缺必填槽即报错，禁静默留空（铁律31）。
