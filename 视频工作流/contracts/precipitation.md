# 契约：降水与水体（雨滴 / 溅射 / 涉水 / 水面波）

## 依赖 / 被依赖
- 依赖: `math`（常量由代码定义，禁硬编码在业务模块）
- 被依赖: `driver`(族分派), `build_video`(成片), `environment`(环境层)
- 禁止: 本模块不得依赖 solver / composite / pose（保持纯函数层）

## 改前必读
- `IMPROVE_water.md` —— 业界公式出处、已踩坑、待办
- 改动任何公式必须同步 `water_selfcheck.py` 的证伪项

## 核心原则（铁律95-98）
- **铁律95**：雨/水的一切表现由「无量纲数 + 经验公式」算出，禁凭印象填像素或频率
- **铁律96**：雨强 I(mm/h) 是唯一输入量纲，粒径分布/数量/倾斜/拖尾全部由它派生
- **铁律97**：溅射与否由 We·Oh^-0.4 ≥ K_c 判定，禁写死"会溅/不溅"
- **铁律98**：涉水失稳用 d·v（倾倒）与 d·v²（滑移）双判据，禁单一阈值

## 族扩展
