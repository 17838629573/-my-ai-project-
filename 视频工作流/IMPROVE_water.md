## 一、业界怎么做到"公式不多、能覆盖很多情况"

核心答案是：**用无量纲数做桥，用少数经验公式做底。**

| 现象 | 业界做法 | 我们落地 |
|---|---|---|
| 雨滴下落 | 终速经验式 `U(D)`，一个式子覆盖 0.1–6mm | `drop_terminal_velocity` |
| 雨滴大小分布 | Marshall-Palmer `N(D)=N0·e^(-ΛD)`，`Λ=4.1·I^-0.21` | `marshall_palmer_lambda` |
| 普通雨 vs 风吹雨 | **同一个公式**，只差倾斜角 `α=arctan(v_wind/U)` | `rain_inclination` |
| 雨线长度 | `L = V·t + 2R`（曝光位移 + 滴径） | `streak_length` |
| 水花溅不溅 | `K = We·Oh^-0.4` 与 `Kc` 比较，**不写死"画水花"** | `splash_regime` |
| 入水失稳 | 双判据 `d·v`（倾倒）、`d·v²`（滑移） | `wading_state` |
| 水面涟漪 | 一条色散关系 `ω²=(gk+σk³/ρ)tanh(kh)` | `wave_speed` |

**关键洞察**：普通雨和斜雨在业界**不是两套代码**，只是 `v_wind` 从 0 变成非零——
倾斜角自动从 0° 变到 45°。这正回答"是不是几个系数就能表现很多种情况"：**是。**

## 四、本轮踩过的坑（别重犯）

1. **终速模型不能只留一个。** Uplinger 对 5mm 大滴准（9.15 vs Gunn-Kinzer 9.09），
   Atlas-Ulbrich 幂律在 5mm 偏高（11.1）。默认 Uplinger，Atlas 留作交叉验证
   （自检要求 1–3mm 内两者差 <15%）。
2. **Marshall-Palmer 有直径版和半径版两套 N0。** 半径版 Λ 是直径版的 2 倍。
   混用会让滴数差一个量级。我们统一用**直径版** `N0=8000 m^-3 mm^-1`。
3. **Strouhal 那套不能拿来算雨。** 上轮旗帜的错误就是误用涡脱落频率；
   雨滴不是钝体绕流，用终速经验式。
4. **毛细波和重力波必须分开。** `λ<1.7cm` 是毛细主导，相速随波长减小而**增大**；
   重力波相反。混为一谈涟漪会朝错误方向跑。
