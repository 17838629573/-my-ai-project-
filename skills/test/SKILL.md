# 测试找 bug

输入：可运行的项目。
产物：测试结果 + 修复记录。

两条路径（步骤 2 定）：**TDD / 契约先行**的测试已在步骤 3 随代码写好，本步跑全量 + 补充集成用例；**事后测试**（原型 / 一次性脚本，即下方流程）从第 1 步开始。

1. 测试框架在不在（pytest / npm test…）？不在 → 读 `skills/halt/SKILL.md`（可降级：语法检查 + 边界手动跑，须声明降级）。
2. 全量跑现有测试，记录每个失败项。
3. **三层扫 bug**：
   - 一层：看报错 / 堆栈 / 退出码，定位到 文件:行。
   - 二层：grep 全项目搜同类错误模式，一次性修净。
   - 三层：边界扫描（空值、越界、并发、资源释放）。
4. 每个问题 → 读 `skills/fix/SKILL.md` 修复。
5. 全部修完 → 重跑全部测试 + 受影响模块 quick-check 回归。

过门：测试全绿（降级时降级手段全执行并声明）+ 无未解决错误 + 验证声明五项完整。
