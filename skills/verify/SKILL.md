# 验证

被调用时做两件事：

1. **选手段实际跑**：按改动范围选——语法检查 / 单元测试 / 集成测试 / 手动运行 / 边界扫描。禁止只说"验证通过"。
2. **输出验证声明，五项缺一不可**：
   - **手段**：跑了什么命令
   - **理由**：为什么选这个手段
   - **结果**：关键输出数字（如 `12 passed`）
   - **影响**：本次改动碰了哪些文件 / 功能
   - **无回归**：相关旧功能没破坏的依据

过门：五项齐全 + 命令输出为通过。
不通过 → 转 `skills/fix/SKILL.md`。

## 合格验证声明示例
> 手段：`pytest tests/test_auth.py -q`
> 理由：改动仅在 `user_auth.py`，该模块单测覆盖最全
> 结果：`12 passed, 0 failed`
> 影响：仅 `user_auth.py` 与调用它的 `login_route.py`
> 无回归：旧登录流程单测仍全绿（附 pytest 输出）
