# 授权跟踪（.track.md）

授权过的事不重复问，到期或撤销自动失效。**文件存在 = 有效，文件不存在 = 无效，无额外标记位。**

## 三种有效期
- **临时**：不落文件，用完就忘，下次重新问。
- **半永久**（默认 90 天，天数用户可改）：写 `.track.md`，到期重问；用户说"不要了" → 删该条目。
- **永久**：写 `.track.md`，永不过期，再也不问。

## 规则
1. **代码强制门禁**（铁律8）：执行任何授权依赖操作前，先跑 `python3 scripts/enforce.py check-auth <track名>`。退出码非 0 → 暂停，走下面重新询问，不可跳过。
2. 要授权前，先读对应 `.track.md`（跟随步骤文件同名，如 `skills/split.track.md`；项目级长期授权放项目 `tracks/`）。
3. 有未过期条目 → 直接执行，不再问。
4. 没有 / 已过期 → 问用户，顺带给三个选项：临时 / 半永久（90 天可改）/ 永久。
5. 临时不落；半永久 / 永久按下面格式落盘；到期日落笔时算好（时间 + 有效期）。
6. 用户撤销 → 删对应条目块，块删空就删文件。
7. 用户拒绝 → 不落盘（等同临时，用完即忘），本轮走 halt 停下或换路径；下次需要重新问。

## 条目格式（每块一条）
```
问: <要授权的事，如：写入 /src 目录的权限>
答: 半永久
有效期: 90天
时间: 2026-09-06
到期日: 2026-12-05
```
永久条目：有效期写 `永久`，到期日写 `-`。
