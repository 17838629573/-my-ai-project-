# 架构师层级

## 层级
- **L0 总架构师**：拆顶层模块，定全局结构
- **L1..Ln 次级架构师**：逐层拆解，每层拆自己那一层
- **末层代码 AI**：按最底层契约直接写代码，不再拆

## 层间纪律
1. 上层对下层实现**只读**：可看实现方式判断是否符合契约，禁止修改下层代码。
2. 下层实现方式错误 → 上层**只改自己的契约**使其更精准，让下层按新契约重做；不越层改代码。
3. 契约是层间唯一接口：上层定义 → 下层实现 → 不符则上层改契约 → 下层重做。

## 契约图
- 每个架构师**只负责自己的契约图**（`deps.md` 中 `# L{n}` 自己那段）。
- **全局契约图** = 各层契约图汇总（`deps.md` 全文），拆完输出，供以后更改（改架构先改对应层）。
- 契约图必须与代码对应：`scripts/dep_check.py` 校验不一致 → 停下问用户。
